# TubeFind

صفحة عربية للبحث داخل YouTube وYouTube Shorts وعرض النتائج في بطاقات مصغرة. تحتوي على فلاتر لنوع المحتوى، تاريخ النشر، المدة الزمنية، وترتيب النتائج، مع أزرار تنقل بين صفحات النتائج.

## التشغيل

افتح ملف `index.html` مباشرة في المتصفح. لا يحتاج المشروع إلى Node.js أو خادم أو تثبيت حزم.

## التشغيل بدون مفتاح

هذه النسخة لا تستخدم YouTube Data API ولا تطلب أي مفتاح. البحث يعتمد على مصدر بحث عام متوافق مع YouTube، ثم تعرض الصفحة النتائج في بطاقات وتطبق فلاتر النوع والمدة والتاريخ. لأن المصدر العام قد يتغير أو يتوقف أو يكون محجوباً في بعض الشبكات، أضفت زر «فتح نتائج البحث في YouTube» كخطة بديلة عند تعذر جلب البطاقات.

يتم تعريف Shorts تقريبياً بأنها فيديوهات مدتها 60 ثانية أو أقل، لأن YouTube لا يوفّر في البحث العام علامة Shorts ثابتة يمكن الاعتماد عليها دائماً.
